# WordPress Blog Deployment on AWS Lightsail
# Project Overview
This project demonstrates the deployment of a WordPress blog website using Amazon AWS Lightsail. WordPress is an open-source content management system (CMS) used to create and manage websites and blogs.
The website is hosted on an AWS Lightsail instance, providing a simple, cost-effective, and reliable cloud hosting solution.

# Project Objectives
- Deploy a WordPress website on AWS Lightsail.
- Understand cloud hosting infrastructure.
- Configure and manage a WordPress blog.
- Learn basic website administration.
- Explore AWS cloud services and hosting.

# Technologies Used

- **Cloud Platform:** Amazon Web Services (AWS)
- **AWS Service:** Amazon Lightsail
- **CMS:** WordPress
- **Web Server:** Apache
- **Database:** MySQL / MariaDB
- **Operating System:** Linux
- **Protocol:** HTTP / HTTPS

# Architecture

```text
           User / Client
                |
                |
           Internet
                |
                |
      AWS Lightsail Instance
                |
          Apache Web Server
                |
           WordPress
                |
          MySQL Database
```

# Implementation Steps

1. Created an AWS account.
2. Opened Amazon Lightsail.
3. Created a WordPress instance.
4. Selected the Linux-based WordPress blueprint.
5. Launched the instance.
6. Configured the static IP address.
7. Accessed the WordPress admin dashboard.
8. Customized the website using WordPress.
9. Created Home, About, and Blog pages.
10. Configured the website for public access.

# Project Features

- WordPress blog website.
- Home page.
- About page.
- Blog posts.
- WordPress admin dashboard.
- Cloud-based hosting.
- Public website accessibility.

# Learning Outcomes

- Understanding AWS Lightsail.
- WordPress installation and configuration.
- Linux-based cloud hosting.
- Web server fundamentals.
- Website management.
- Basic cloud deployment concepts.
